# Wavemaker

一个程序化的海浪发生器，往"自然声场引擎"的方向走。零采样，所有声音都是实时算出来的，所以永远不循环。

- `index.html`：海浪。可以直接打开的原型。浪高、周期、拍岸力度、冲滩、距离、风、海鸥、材质（沙滩 / 卵石滩 / 礁石）、种子都可调；空格键"拍一浪"、G 键"叫一声海鸥"；可离线渲染导出 48 kHz WAV。
- `sparkler.html`：仙女棒，三种口味。原味是几千颗极小火花糊成的颗粒嘶声，快熄灭时断续；电子是一颗颗的"叮"（第一版，像拉长的鞭炮）；鼓机把电子的火花对齐到 BPM 网格当踩镲。可同时点多根，可导出。引擎在 `sparkler.js`。
- `dandelion.html`：蒲公英。对着麦克风吹（或按住按钮），种子飞走、落地生根、长成新的一株。每颗种子是五声音阶上的一个音，是一个会自己生长的生成式乐器。
- `analyze.html`：分析。把真实录音或视频拖进去（浏览器自己解码，mp4 / mov / m4a / mp3 / wav 都行），算出各倍频程能量、频谱斜率、浪的周期、拍岸时的亮度，和引擎输出放在同一把尺子上比。
- `ocean.js` / `sparkler.js`：海浪和仙女棒引擎，被各自的页面和分析页共用。`analysis.js`：分析模块，纯 JS 的 FFT 和统计。
- `style.css`：所有页面共用的样式。
- `docs/VISION.md`：想法的发散、第一个版本该 build 什么、目前遗漏的部分、路线图（Web → 真实海滩数据 → 硬件）。

## 运行

直接用浏览器打开 `index.html` 即可，不需要构建，也不需要网络。
如果浏览器限制 `file://`，在目录下起一个静态服务器：

```
python3 -m http.server 8000
```

然后访问 http://localhost:8000 。

## 引擎结构

引擎只有两个原语：**层**（噪声源过滤波器，由包络驱动）和**颗粒流**（强度随时间变化的泊松过程，往声音里撒颗粒）。海浪的涌、拍岸、冲滩、风是层；卵石、泡沫、火花、蒲公英种子是颗粒流。

### 海浪

所有层的噪声源都是粉红噪声（每倍频程降 3 dB），只有泡沫、飞溅和卵石用白噪声。第一版全部用白噪声，听起来像水泼在热锅上；第二版用 `analyze.html` 对着文献里海滩录音的典型频谱调过，频谱斜率从 +2.3 dB/倍频程变成 -3.4 到 -4.8。

每一层是一个独立的噪声源经过滤波器、增益、声像：

| 层 | 作用 |
|---|---|
| 远涌床（左右各一） | 一直存在的低频底 |
| 涌 | 每一浪涨起来的过程，低通滤波器随之打开 |
| 拍岸 | 带通噪声的一次爆发 |
| 冲滩 | 高频嘶声沿海岸线从一侧跑到另一侧，水变薄时变亮、回退时变暗 |
| 泡沫 | 冲滩后留在沙上的细碎嘶声 |
| 卵石 | 回退时的一串短噪声脉冲（仅卵石滩） |
| 礁石 | 拍岸时的一声低频闷响（仅礁石） |
| 风 | 阵性的带通噪声 |
| 海鸥 | 锯齿波经带通滤波和颤音，一到三声一组 |

调度器每 300 ms 往前排 2.5 s 的事件；导出时用 `OfflineAudioContext` 一次排完整段。同一个种子得到同一片海。
