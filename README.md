# Wavemaker

一个程序化的海浪发生器，往"自然声场引擎"的方向走。零采样，所有声音都是实时算出来的，所以永远不循环。

- `index.html`：可以直接打开的原型。浪高、周期、拍岸力度、冲滩、距离、风、海鸥、材质（沙滩 / 卵石滩 / 礁石）、种子都可调；空格键"拍一浪"、G 键"叫一声海鸥"；可离线渲染导出 48 kHz WAV。
- `docs/VISION.md`：想法的发散、第一个版本该 build 什么、目前遗漏的部分、路线图（Web → 真实海滩数据 → 硬件）。

## 运行

直接用浏览器打开 `index.html` 即可，不需要构建，也不需要网络。
如果浏览器限制 `file://`，在目录下起一个静态服务器：

```
python3 -m http.server 8000
```

然后访问 http://localhost:8000 。

## 引擎结构

每一层是一个独立的噪声源经过滤波器、增益、声像：

| 层 | 作用 |
|---|---|
| 远涌床（左右各一） | 一直存在的低频底 |
| 涌 | 每一浪涨起来的过程，低通滤波器随之打开 |
| 拍岸 | 带通噪声的一次爆发 |
| 冲滩 | 高频嘶声沿海岸线从一侧跑到另一侧，水变薄时变亮、回退时变暗 |
| 泡沫 | 冲滩后留在沙上的细碎嘶声 |
| 卵石 | 回退时的一串短噪声脉冲（仅卵石滩） |
| 礁石 | 拍岸时的一声低频闷响（仅礁石） |
| 风 | 阵性的带通噪声 |
| 海鸥 | 锯齿波经带通滤波和颤音，一到三声一组 |

调度器每 300 ms 往前排 2.5 s 的事件；导出时用 `OfflineAudioContext` 一次排完整段。同一个种子得到同一片海。
